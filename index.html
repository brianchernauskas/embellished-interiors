Siri

Set up “Hey Siri, add hours”
  1. Tap Copy Shortcut link above.
  2. Open the Shortcuts app, make a new shortcut, and name it Add Hours. That name is what she says to Siri. Avoid “Log Time”: Siri treats it as “what time is it?”.
  3. Add the action Ask for Input. Input type Text, question “What’s the entry?”.
  4. Add the action Open URLs (or Open URL). In its link field, paste the copied link, then tap right after the = at the end and insert the Provided Input variable from step 3.
  5. Say “Hey Siri, add hours”, wait for the question, then answer: “fifteen minutes Park Villas, call from Cristina.” A page opens saying it was added. Then open this app and tap Save.
